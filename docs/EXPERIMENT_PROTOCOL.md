# Experiment Protocol

## 1. Перед запуском

Фиксируются: HYP-ID, цель, гипотеза и нулевая гипотеза, организм и версия модели, входные данные, параметры, метрики, критерии, seed и версия кода.

## 2. Во время эксперимента

Сохраняются конфигурация, логи, seed, состояние среды, ключевые состояния организма, ошибки и предупреждения.

## 3. После запуска

FACT — что измерено.
CHECK — как проверено.
RESULT — результат.
DECISION — следующий шаг.
FIXATION — что сохраняется.

## 4. Запрет

Нельзя менять параметры после просмотра результата и выдавать повторный запуск за исходный эксперимент.

## 5. Сравнение

Для каждого организма нужны baseline, модель, эталонное поведение, количественные метрики и воспроизводимый локальный запуск.
