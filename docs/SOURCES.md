# Sources

Этот файл — реестр внешних источников.

Для каждой модели фиксируем:

- название проекта/публикации;
- URL;
- дату доступа;
- версию или commit;
- лицензию;
- какие данные используются;
- какие части являются нашими адаптерами;
- ограничения источника.

Первый кандидат для исследования: C. elegans / OpenWorm и связанные воспроизводимые модели.

Второй кандидат: BAAIWorm.

Следующий масштаб: Drosophila whole-brain/connectome models.

Никакие внешние результаты не считаются результатами Digital Organisms Lab до независимого запуска и фиксации конфигурации.
