# C. elegans

Первый основной объект Digital Organisms Lab.

## Что исследуем

- connectome;
- нейронную динамику;
- мышцы и тело;
- сенсорику;
- среду;
- обратную связь;
- воспроизводимость поведения.

## Важно

Этот каталог не утверждает, что модель уже является полноценной цифровой копией червя.

Каждая внешняя модель подключается как отдельный адаптер и проверяется против опубликованных данных.

## План

1. Зафиксировать источники данных.
2. Зафиксировать версию модели.
3. Запустить baseline.
4. Проверить простое поведение.
5. Добавлять слои по одному.
6. Измерять изменение после каждого слоя.
