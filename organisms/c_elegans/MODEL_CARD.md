# C. elegans — Model Card

## Status

## Требуется

- источник модели;
- лицензия;
- версия;
- формат connectome/нейронной модели;
- модель тела;
- сенсорика;

- эталонные поведенческие данные.

Модель не считается воспроизведённой, пока её поведение не сравнено с независимыми эталонными данными.

## Rule

Не заменять отсутствующие биологические данные предположениями без явной маркировки.
