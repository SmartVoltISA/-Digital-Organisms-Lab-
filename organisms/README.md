# Organism adapters

Каждый организм подключается через отдельный адаптер.

Правила:

- исходная модель и лицензия фиксируются;
- версия источника фиксируется;
- данные не смешиваются с результатами экспериментов;
- адаптер не изменяет каноническую модель;
- одинаковый интерфейс должен позволять запускать разные модели.

Минимальный интерфейс:

`load → reset → step → observe → act → state → metrics`
