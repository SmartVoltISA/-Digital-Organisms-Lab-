# Digital Organisms Lab

Лаборатория цифровых организмов: структура, динамика, среда и поведение.

## Цель

Исследовать, какие элементы и связи необходимы, чтобы цифровая модель воспроизводила наблюдаемое поведение организма.

## Принцип

FACT → CHECK → RESULT → DECISION → FIXATION

Никаких выводов без воспроизводимого эксперимента и сравнения с исходными данными.

## Слои

1. Structure — клетки, нейроны, связи.
2. Dynamics — состояния и изменения во времени.
3. Body — механика и физиология.
4. Environment — внешняя среда.
5. Feedback — замкнутые причинные контуры.
6. Behavior — измеряемое поведение.

## Организмы

- C. elegans — первый основной объект.
- Drosophila — следующий масштаб.
- Другие организмы — после появления проверяемого адаптера.

## Локальный запуск

Требования: Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
python examples/minimal_organism.py
```

Первый пример — не биологическая копия, а воспроизводимый стенд для проверки контура «состояние → среда → действие → обратная связь».

## Структура

- `docs/` — протоколы и критерии.
- `organisms/` — адаптеры и модели.
- `experiments/` — эксперименты и результаты.
- `examples/` — локальные запускаемые примеры.
- `data/` — небольшие проверяемые данные и метаданные.

## Статус

Рабочая лаборатория. Биологические утверждения фиксируются отдельно от инженерных гипотез.
